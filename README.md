# GONA Website

Official marketing website for **GONA Super App** / **GONA Technologies**.

Production domain: [https://gonasuperapp.com](https://gonasuperapp.com)

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm start
```

Requires Node.js 20.9+.
